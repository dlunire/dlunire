Onboarding

Inicio rápido

Cinco pasos para tener DLUnire corriendo y una ruta respondiendo.

  1. 1

    Crear el proyecto

    Instala el skeleton. Composer trae dlcore, y con él dlroute y dlstorage.

    terminal 
    $ composer create-project dlunire/dlunire mi-app$ cd mi-app
  2. 2

    Configurar el entorno

    Archivo .env.type en la raíz: cada variable tiene tipo estático. Con un mínimo basta para arrancar sin base de datos (rutas, plantillas, JSON). Las variables DL_DATABASE_* y DL_PREFIX solo hacen falta si va a usar el ORM — vea Inicio rápido · base de datos.

    .env.type · mínimo 
    DL_PRODUCTION: boolean = falseDL_LIFETIME: integer = 3800

    Opcional en este inicio: correo, reCAPTCHA, CORS (DL_CORS_ORIGINS). El ejemplo completo de BD está en el paso ORM.

  3. 3

    Registrar una ruta

    En routes/web.php — se cargan al arrancar con Project::run().

    routes/web.php 
    <?php use DLRoute\Requests\DLRoute; DLRoute::get('/api/health', fn () => ['status' => 'ok',]);
  4. 4

    Escribe tu dominio en app/

    Controladores, modelos y plantillas viven en el skeleton. Ejemplo de modelo:

    app/Models/Products.php 
    <?phpnamespace DLUnire\Models; use DLCore\Database\Model; final class Products extends Model {}

    Con DL_PREFIX = "dl_"

    Products → dl_products

    Plantillas en resources/*.template.html

  5. 5

    Levantar el servidor

    Document root en public/. Con el script del skeleton:

    terminal 
    $ composer run dev# → http://localhost:3000/

    Equivalente: php -S localhost:3000 -t public/

ORM · DLCore

Inicio rápido · base de datos

Configure MySQL en .env.type, defina un modelo y lea o cree registros. Asume el proyecto del inicio rápido ya creado.

  1. 1

    Conexión en .env.type

    Copie desde .env.type.example si aún no tiene archivo. El prefijo DL_PREFIX nombra las tablas del ORM (Products → dl_products).

    .env.type 
    DL_PRODUCTION: boolean = false DL_DATABASE_HOST: string = "127.0.0.1"DL_DATABASE_PORT: integer = 3306DL_DATABASE_USER: string = "root"DL_DATABASE_PASSWORD: string = ""DL_DATABASE_NAME: string = "mi_app"DL_DATABASE_CHARSET: string = "utf8mb4"DL_DATABASE_COLLATION: string = "utf8mb4_unicode_ci"DL_DATABASE_DRIVE: string = "mysql" DL_PREFIX: string = "dl_" # En desarrollo — monoinquilino:MULTITENANT: boolean = false

    Cree la base mi_app en MySQL y la tabla que usará el modelo (p. ej. dl_products con columnas de su dominio).

  2. 2

    Modelo vacío

    Con el prefijo del entorno, la clase Products apunta a dl_products. Opcional: fije la tabla con protected static ?string $table = '…';.

    app/Models/Products.php 
    <?php namespace DLUnire\Models; use DLCore\Database\Model; final class Products extends Model {// Tabla: {DL_PREFIX}products → dl_products}
  3. 3

    Crear, leer y filtrar

    Métodos del modelo: create, get, where, paginate, all. get() aplica un tope de seguridad (p. ej. 1000 filas) para no tumbar el servidor con tablas masivas. Para listados use paginate(). all() quita el tope — solo si sabe que el conjunto es acotado. Los filtros se encadenan y terminan con →get().

    ejemplo ORM 
    use DLUnire\Models\Products;use DLCore\Database\Model; // InsertarProducts::create(['product_name' => 'Teclado mecánico','price' => 189000,]); // get(): tope de seguridad (p. ej. 1000 filas), no toda la tabla$rows = Products::get(); // Filtrar (encadenar where → get)$items = Products::where('price', '>', '100000')->where('product_name', 'LIKE', '%teclado%', Model::AND)->get(); // Listado paginado (recomendado en APIs / UI)$page = Products::paginate(page: 1, rows: 20);

En desarrollo

Autenticación · DLAuth

Básico · no listo para producción

Estado

DLAuth es un autenticador básico del kernel y está en desarrollo. Sirve solo para demos o pruebas muy simples.

No se recomienda en aplicaciones reales ni en producción.

Qué usar mientras se desarrolla

Hasta que el autenticador de DLUnire sea robusto, integre otra solución en su capa de aplicación:

  • JWT
  • OAuth2 / OIDC
  • Librerías maduras
  • IdP de su infra
En desarrollo

MULTITENANT

Modo SaaS · una base por dominio

Estado

La variable MULTITENANT puede declararse en .env.type, pero el aislamiento completo aún no está terminado (depende de DLParse).

En monoinquilino use MULTITENANT: boolean = false.
